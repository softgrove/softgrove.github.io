MDF Cut Calculator: Plan Sheets, Kerf and Part Layout

An area total can estimate how much MDF the parts contain, but it cannot prove that the rectangles fit. Use the free cut list optimizer as an MDF cut calculator, then check the layout against the actual sheets and saw setup.

Enter the measured MDF sheet as stock, add each finished part and quantity, and set the blade kerf to the width removed by your planned cut. The calculator returns a sheet count, cutting diagram, placed parts and yield for the entered dimensions. Review the diagram and any unplaced parts before buying or cutting material.

Set up the MDF sheet you will actually cut

Measure the sheet or confirm the supplier's listed dimensions, then enter that width and length as stock. If an edge is damaged or must be squared, reduce the usable stock dimensions or reserve that trim before laying out parts. Keep different thicknesses and finishes in separate calculations because one sheet cannot replace another.

Enter finished part dimensions rather than adding kerf to every part. The calculator reserves kerf between cuts; adding it to the part sizes as well would count the same material twice.

  • Actual usable sheet width and length
  • Finished width, length and quantity for every part
  • Measured blade kerf for the planned saw setup
  • Separate runs for each thickness or non-interchangeable finish

Use the free calculator for the first layout

Open the cut list optimizer, replace the default stock dimensions with your MDF sheet, and add the parts. The browser tool accepts up to ten parts in total, including repeated quantities, and allows rotation. Generate the diagram, then compare the parts placed with the source list.

If a part is left unplaced, first check its dimensions, units and orientation. A small difference in usable sheet size or kerf can change whether a tight row fits, so do not force the plan by entering zero kerf or a larger sheet than the material in front of you.

Check more than the reported sheet count

A valid rectangle layout is still only a plan. Trace the cuts from the full sheet to the finished parts and confirm that each step can be supported and referenced with the tools available. Label repeated parts and confirm quantity, thickness and finished dimensions against the project before cutting.

Yield is useful for comparing layouts built from the same inputs. It does not show whether the leftovers are useful for a future part, so record any offcut you intend to keep with its measured dimensions.

Move the plan to Boardcut when the job grows

The free browser calculator is intended for a quick layout of up to ten parts. Boardcut for iPhone supports larger part lists, multiple material groups and grain-direction locking, while keeping sheet count, yield and ordered cut steps with the plan.

Use the same source list in either workflow: part name, finished width and length, quantity, material, thickness and any orientation requirement. Keeping one clean list makes the calculated layout easier to audit.

Questions

Can the calculator use a custom MDF sheet size?

Yes. Enter the usable width, length and quantity of the stock you have rather than relying on a nominal size.

Should I add kerf to every MDF part dimension?

No. Enter finished part dimensions and set kerf once in the calculator so it is reserved between cuts.

Can the MDF cut calculator mix sheet thicknesses?

Run separate layouts for stock that is not interchangeable. Boardcut supports multiple material groups when the project needs them in one plan.

Does the calculator guarantee the least possible MDF waste?

No. It produces a usable heuristic layout, not a mathematical proof of the global optimum. Compare the diagram, sheet count, cut sequence and reusable offcuts before choosing a plan.
