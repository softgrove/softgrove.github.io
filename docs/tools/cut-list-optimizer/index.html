How to use the cut list optimizer (optimiser)

  1. Pick millimetres or inches, then enter the usable length and width of one plywood sheet or board after any damaged edge or squaring trim. The optimizer opens as many sheets of that size as the parts need.
  2. Enter a clear name, finished length, finished width and quantity for each rectangular part. There is no part limit; quantities are expanded into individual placements.
  3. Measure the width removed by the blade and saw setup you will use, then enter that value once. Do not add kerf to the finished part dimensions as well.
  4. Select Generate cutting diagram. The optimizer tries 48 combinations of part order, placement rule and guillotine split and keeps the layout that uses the fewest sheets, then draws a kerf-aware cut sheet.
  5. Compare the part count with the source cutlist, then verify sheet size, orientation, dimensions and a safe cut sequence against the real material. Continue in Boardcut when you need a saved project or a PDF plan.

Set up the sheet before the parts

The sheet is the material you have; parts are the finished rectangles you need from it. Enter the usable sheet dimensions after any damaged edge or squaring trim. A nominal 48 × 96 plywood sheet (1220 × 2440 mm) should only be entered at full size when that whole rectangle is available for the layout. Keep different thicknesses, materials and faces in separate runs when they cannot substitute for one another.

The web optimizer uses one sheet size per run and opens as many sheets of that size as the parts need, so the sheet count it reports is a purchase estimate. If you must work only from stock already in the shop, compare that count with what you have before cutting.

Prepare a cutlist the optimizer can check

Use finished dimensions for every part and give repeated pieces a stable name. Quantity is expanded into individual placements, so two cabinet sides entered with quantity 2 appear twice in the diagram. Check the total against the project list before generating a diagram; an efficient cut sheet is still wrong when a shelf or divider is missing.

The browser tool allows every part to rotate and uses one kerf value for the whole layout. It does not model grain direction, defects, edge banding or different kerfs for different operations. If a visible face must keep its grain orientation, treat the web result as an estimate or continue the project in Boardcut for iPhone, which supports part-level grain locks.

Run a simple layout check

For a plywood project, start with the measured usable sheet size, then enter each part exactly as it appears on the source cut list. Set kerf from a representative test cut. Generate the diagram and compare the reported part count with the total quantity you entered. If a part is larger than the sheet in both orientations, the tool says so instead of drawing a layout; confirm its dimensions and the sheet size before changing the design.

Do not set kerf to zero or enlarge the sheet simply to force a fit. A row that looks exact on paper can fail at the saw because every separating cut removes material. The kerf width guide shows how to measure that loss, and the plywood cut calculator guide explains why an area estimate can undercount sheets.

How the cut sheet is built

The cut list optimizer runs the same guillotine packer as the Boardcut web calculators. It sorts the parts four ways (by area, longest side, height and width), scores each candidate position four ways (remaining area, short-side fit, long-side fit and bottom-left) and splits the leftover rectangle three ways (larger piece first, vertical first, horizontal first). That is 48 layouts per run; the one that uses the fewest sheets wins, and on a tie the one that leaves the largest offcut on the last sheet.

Every placement reserves one blade kerf between neighbours and can be reached by straight, edge-to-edge cuts. This is a practical heuristic search, not a proof of the global optimum: a layout outside those 48 may still save a sheet. Use the diagram as a planning aid, not as a substitute for measuring the real stock and checking a safe, workable cut sequence.

Read sheet count, parts and yield

Sheets used is the number of sheets opened by the layout. Parts must match the total quantity in the source cutlist. Yield is part area divided by the area of every sheet used; it does not credit reusable offcuts or prove that the sequence suits your saw. Each sheet shows how much of its area is used, and the drawing labels each part and its dimensions so you can trace the result back to the list.

Before making board cuts, check every part name, dimension and quantity, then inspect the sheet size and each tight row. Confirm grain direction outside this tool and plan how the material will be supported through the cuts. For a paper handoff, use the free woodworking cut list template or the plywood cutting diagram worksheet; for a fuller waste review, use the plywood waste guide.

Cut list optimizer FAQ

How do I turn a cut list into a cutting diagram?

Pick millimetres or inches, enter the usable sheet size, then each finished rectangular part and quantity. Set the measured blade kerf and generate the diagram. Cut list optimiser is the UK spelling of cut list optimizer; both refer to this layout tool. Check every part against the diagram before cutting.

Does the plywood cut calculator work in millimetres?

Yes. Switch the unit to millimetres and enter a sheet such as 2440 × 1220 mm with a 3 mm kerf. Switching units converts the numbers already on the form, so a layout entered in inches reads the same in millimetres. The layout engine itself is unit-free.

Is there a part limit?

No. The free web optimizer accepts any number of parts and quantities and opens as many sheets of the chosen size as the layout needs. Very large lists simply take a moment longer to calculate in the browser.

Is this a true guillotine cut layout?

Yes. Every placement sits in a rectangle that can be reached by straight, edge-to-edge cuts across the remaining stock, with one blade kerf reserved between neighbours. The optimizer compares several part orders, placement rules and split directions and keeps the layout that uses the fewest sheets, but that search does not prove the mathematical minimum, so check the diagram before cutting.

Can I lock grain direction or mix sheet sizes?

Not in this web tool. It allows every part to rotate and uses one sheet size per run; run different materials or thicknesses separately. Boardcut for iPhone supports grain-direction locking and multiple material groups.

What does yield mean on the cut sheet?

Yield is the placed part area divided by the area of every sheet the layout used, as a percentage. Reusable offcuts are not credited. Blade kerf affects the space left for parts, so enter your blade's actual cut width.
